# Mapa da Câmara Fria

## O que é

Uma ferramenta para desenhar, em tamanho proporcional, como as pilhas de caixas ficam dentro do container da câmara fria. Serve para planejar onde cada pilha vai, conferir se tudo cabe e imprimir a folha para quem vai descarregar/organizar.

## Como abrir

No menu, grupo **Logística → Câmara Fria**. O item só aparece para quem tem a permissão **Mapa da Câmara Fria**. A tela abre em página própria; para voltar ao sistema use o link "← Sistema" no topo.

Se aparecer "Acesso restrito", peça a um administrador para liberar em **Usuários → Permissões → Logística → Mapa da Câmara Fria**.

## Como usar

- **+ Pilha**: adiciona uma pilha de caixas no mapa. Arraste para o lugar desejado.
- **+ Parede A / + Parede B**: adicionam divisórias/paredes de referência.
- **Selecionar uma pilha**: aparecem os botões **Girar 90°**, **45°**, **Duplicar** e **Excluir**, além dos campos de medida da pilha.
- **Medidas**: ajusta o tamanho interno do container e o tamanho padrão das pilhas novas.
- **Zoom (− / +)**: aumenta ou diminui o mapa na tela.
- **Porta**: toque na faixa "PORTA" no mapa (ou no botão de lado da porta) para trocar a porta de lado.
- **Espelhar o mapa**: se você começou pelo lado errado, inverte o desenho inteiro.
- **Salvar arquivo / Abrir arquivo**: guarda o layout em um arquivo ou carrega um já salvo.
- **Limpar tudo**: apaga o layout (pede cuidado — não dá para desfazer).
- **Imprimir**: monta a folha com o mapa e a legenda das pilhas na própria página e abre a impressão. Funciona no computador e no iPad.

## Onde fica salvo

O layout é salvo automaticamente **neste aparelho e neste navegador**. Outro celular, outro computador ou outro navegador não vê o mesmo desenho; para levar para outro aparelho use **Salvar arquivo** e **Abrir arquivo**.

## Permissão

Acesso liberado pela permissão **Mapa da Câmara Fria** (grupo Logística). Administradores têm acesso automático. Sem conexão com o sistema, a ferramenta não abre (ela confere o acesso ao carregar).
