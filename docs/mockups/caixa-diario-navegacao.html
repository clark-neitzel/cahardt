O que cada número faz
  • 1
    Setas ‹ › pulam um dia para trás ou para frente. Clicando na data no meio abre o calendário (igual hoje). O botão Hoje volta direto para o dia atual. A seta › desliga quando já está em hoje (não tem caixa no futuro).
  • 2
    Pílulas = todo mundo que teve caixa com movimento nesse dia, já com a cor do status e o valor a prestar. Um clique troca o caixa — não precisa mais abrir o menu de pessoas. Os que precisam de ação aparecem primeiro (a conferir, devolução pendente…); os prontos vão para o fim. No celular a faixa rola para o lado.
  • 3
    Aviso de dias anteriores: se algum caixa de outro dia ainda está esperando conferência, aparece a faixa amarela com um link que pula direto para aquele dia.
Cores das pílulas
● A conferirFolha impressa / enviada — dinheiro esperando ser contado. Ponto piscando = precisa de ação.
● DevoluçãoTem devolução esperando conferência no caixa.
AbertoDia em andamento — motorista ainda na rua / lançando.
A fecharDinheiro já conferido, falta só fechar o caixa.
FechadoCaixa fechado, aguardando a conferência final do admin.
✓ ConferidoTudo certo, finalizado.

Quem não teve movimento no dia não aparece nas pílulas (dá para escolher pelo botão “+ outros”, que abre a lista completa).
