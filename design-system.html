Regras de Ouro

o que sustenta o tema — e o que nunca fazer

Sempre

  • Fundo creme bg-secondary como canvas — nunca branco puro na página
  • Botão = pílula (rounded-full) com active:scale-95
  • Verde certo no lugar certo: primary p/ ação, primaryDark p/ hover e títulos, house p/ bandas escuras
  • Valores monetários: font-bold text-primaryDark (vencido: vermelho), alinhados à direita
  • Mobile-first: tabela vira card, grid 2 col no celular, tap 44px
  • cd frontend && npm run build antes de TODO commit

Nunca

  • Mudar as cores semânticas dos badges (verde=pago, vermelho=vencido…)
  • Usar dourado como cor de botão ou status — só cerimônia
  • Introduzir gradientes — o sistema é de blocos de cor sólida
  • Voltar aos azuis de ação (bg-blue-600…) em código novo
  • Animar box-shadow/border (repaint no Android) — só opacity/transform
  • Imprimir via window.open/iframe — sempre @media print na própria página
