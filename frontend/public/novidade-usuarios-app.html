O que mudou

Passo 1: busque a pessoa no cadastro (o mesmo dos clientes) pelo nome, documento ou código. Se ela ainda não existir, o atalho "Cadastrar nova pessoa" leva direto ao Novo Cadastro.

Passo 2: nome, e-mail e telefone já vêm preenchidos do cadastro. Você só define o login e a senha. Ao criar, o painel de permissões abre sozinho para configurar os acessos.

Disponível para administradores.

Embaixo do nome de cada usuário agora aparece o vínculo com o cadastro de pessoas:

  • ✓ Cadastro vinculado — já está ligado à pessoa certa;
  • + Vincular cadastro — usuários antigos (que vieram do Conta Azul) ainda sem vínculo. Um clique abre a mesma busca para ligar à pessoa do cadastro.

Não tem pressa: dá para vincular os antigos aos poucos.

  • Números alinhados e numa linha só — os detalhes do Flex (orçamento e usado) aparecem ao pousar o mouse sobre o valor;
  • Formas de atendimento viraram três botõezinhos uniformes (Presencial · WhatsApp · Telefone) — aceso = visível para o vendedor;
  • No celular, cada usuário vira um cartão organizado, com os indicadores em régua e telefone que nunca quebra no meio.

Antes, os usuários só "nasciam" importados do Conta Azul. Essa importação foi desligada: o app agora é o dono do cadastro de usuários, como já acontece com clientes e fornecedores.

Nada muda para quem já usa o sistema — logins, senhas e permissões continuam exatamente como estão.
