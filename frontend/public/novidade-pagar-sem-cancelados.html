1

"Status: Todos" é como a tela abre — e agora ele mostra tudo, menos os cancelados. A lista fica só com o que ainda vale.

2

"Cancelado" mostra só as parcelas canceladas — bom para conferir um lançamento desfeito.

3

"Todos (com cancelados)" é a opção nova: mostra a lista completa, cancelados junto com o resto, como era antes.

O que mudou? +
Antes, uma despesa cancelada (lançamento errado, pedido desfeito…) continuava aparecendo no meio da lista, ocupando espaço e confundindo na hora de conferir o que falta pagar. Agora a tela abre sem os cancelados — eles continuam guardados no sistema, só não poluem mais a visão do dia a dia.
Nada foi apagado +
Cancelar uma despesa não a apaga — ela só sai da vista. Para revê-la, use o filtro de status: "Cancelado" (só elas) ou "Todos (com cancelados)" (tudo junto). E como os filtros desta tela ficam salvos por usuário, se você escolher ver os cancelados, a tela continua assim até você trocar de novo.
Os totais não mudam +
Os cartões do topo (Vencidas, A vencer, Em aberto, Pago no período) já ignoravam os cancelados — nenhum número muda. A novidade é só na lista, que agora bate com os cartões.

🚀 Para ver os cancelados quando precisar

1

Abra Financeiro → Contas a Pagar.

2

Toque no filtro "Status: Todos" (ao lado da busca).

3

Escolha "Cancelado" para ver só eles, ou "Todos (com cancelados)" para a lista completa.
