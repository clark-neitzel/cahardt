Código de barras vem do cadastro

Na etiqueta, o código de barras não é mais digitado. Ele vem do cadastro de Produtos, uma fonte só, igual para todo mundo.

  • Ao escolher o produto na etiqueta, o campo Código de Barras fica bloqueado e já mostra o código do cadastro.
  • Trocou o produto? O código acompanha sozinho.
  • Precisa mudar o código? Abra Produtos, edite o produto e salve. A etiqueta passa a usar o novo.

Havia etiquetas com código diferente do cadastro e códigos repetidos. Resultado: o leitor do Ajuste de Estoque às vezes caía no produto errado.

Agora o código é um só, e o leitor acha o produto certo.
