O que mudou
  • NÃO: a API recusa na hora (403).
  • PEDE: nada é gravado; o pedido entra na fila de Solicitações para o administrador autorizar ou recusar.
  • SIM: o agente lança direto, exigindo chave anti-duplicidade (Idempotency-Key). Mesmo em SIM, despesas já pagas, lotes grandes, ajustes fora da curva e suspeitas de duplicata continuam pedindo autorização automaticamente.
  • Novo Usuário → Conexão por API: cria um agente sem login/senha já com as permissões de base (sem nunca dar administrador).
  • Kit de Conexão (.md): guia pronto para copiar ou baixar (sem expor nenhum token secreto) com endereço base, matriz atual, códigos de resposta e exemplos curl.
  • OpenAPI vivo: o próprio agente consulta /api/agente/v1/openapi.json e recebe apenas as funções que pode usar.
