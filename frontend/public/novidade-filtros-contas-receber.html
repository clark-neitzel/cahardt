O problema que sumiu

❌ Como era

  • O menu fechava a cada clique — na prática só dava para escolher uma opção por caixa.
  • Ao filtrar, as opções das outras caixas sumiam da lista — inclusive a que você mesmo tinha marcado.
  • Aí a tela não voltava: só limpando todos os filtros de uma vez.
  • Data era quatro campinhos soltos: Venc. de, Venc. até, Pgto de, Pgto até.

✅ Como ficou

  • O menu fica aberto enquanto você marca — várias opções na mesma caixa.
  • As opções são sempre as mesmas, filtrando ou não. Dá para desmarcar quando quiser.
  • A lista se atualiza a cada marcação.
  • Data virou uma pílula só, com Este mês, Últimos 30 dias e setas para navegar.
O que mudou, em detalhe
  • Cada caixa abre um menu com caixinhas de marcar. Marque quantas quiser — o menu só fecha quando você clica fora.
  • Vale para todas: Status Conta, Status Parcela, Origem, Vendedor, Categoria de Cliente, Condição Pgto, Cobrança, Condição na Entrega, Forma Pgto (baixa) e Baixado por. (Origem, Vendedor e Categoria só aceitavam uma opção antes.)
  • Dentro do menu tem "Limpar seleção (N)" para zerar só aquela caixa. Menus longos ganharam busca no topo.
  • A caixa mostra o nome da opção quando é uma só, ou "N selec." quando são várias.
  • Várias opções na mesma caixa = ou. Ex.: Status Conta = Aberto ou Quitado traz os dois.
  • Caixas diferentes = e. Ex.: Vendedor = Jociel e Cobrança = Boleto traz só o que é dos dois ao mesmo tempo.
  • Exemplo do dia a dia: Vendedor = Jociel + Edilson, Cobrança = Boleto, Vencimento = Este mês → tudo que esses dois têm para receber em boleto no mês.
  • Não precisa clicar em Filtrar: a lista atualiza a cada marcação. O botão continua lá para a busca por nome do cliente (ou aperte Enter).

Os quatro campos de data viraram dois controles: Vencimento e Pagamento (baixa).

  • Clique no meio da pílula e escolha: Hoje, Últimos 7 dias, Últimos 30 dias, Este mês, Este ano, Todo o período ou Período personalizado (De/Até dentro do próprio menu).
  • As setas ‹ › pulam o período inteiro: em "Este mês" vão para o mês anterior e o seguinte; em "Últimos 7 dias", de semana em semana.
  • Começa em Todo o período — sem recorte de data, como a tela sempre abriu.
  • É o mesmo controle que já existe no Contas a Pagar.
  • As escolhas ficam salvas por pessoa e voltam quando você reabre a tela.
  • Nos períodos o que fica salvo é o preset, não a data: "Este mês" salvo em agosto abre setembro em setembro. Ninguém fica preso numa data velha.
  • O botão Limpar zera todas as caixas e os dois períodos de uma vez.
  • O contador ao lado de "FILTROS" mostra quantas caixas estão em uso (não quantas opções).

Para começar a usar
1

Abra Financeiro → Contas a Receber (a tela em tabela).

2

Clique numa caixa de filtro e marque quantas opções quiser. Repare que o menu não fecha.

3

Combine com outra caixa — vendedor + cobrança, por exemplo — e veja a lista se ajustar sozinha.

4

No Vencimento, escolha Este mês e use as setas ‹ › para andar de mês em mês.

5

Perdeu-se? Limpar zera tudo de uma vez e a lista volta ao normal.

Dúvida? Chame o Clippy dentro do app 📎 — ele já sabe explicar os filtros novos.
