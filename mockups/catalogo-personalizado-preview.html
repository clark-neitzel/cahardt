Como isso se encaixa no que já existe

Reaproveita o que o sistema já tem: o cálculo valorVenda × (1 + acrescimoPreco/100) é o mesmo do Novo Pedido; a condição vem da tabela de preços (TabelaPreco) e respeita a condição padrão e as condições permitidas de cada cliente (Condicao_de_pagamento / condicoes_pagamento_permitidas). Ao gerar, o app salva um snapshot (preços congelados + validade + token) e devolve o link hardtsalgados.com.br/lista/<token> — servido sem login, como o site de Congelados. Se o produto mudar de preço depois, o link que o cliente já recebeu continua igual.
